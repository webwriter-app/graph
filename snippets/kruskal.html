The Kruskal Algorithm

The Kruskal algorithm is an algorithm from graph theory that is used to find the minimum spanning tree (MST) of an undirected, weighted graph. A spanning tree of a graph is a subgraph that contains all nodes of the graph and has no cycles. A weighted graph is a graph in which each edge is assigned a weight (a cost function).

The Kruskal algorithm works according to the greedy principle, i.e. in each iteration it makes the best decision at that moment and hopes that this decision will yield the best possible spanning tree overall. The algorithm proceeds as follows:

  1. Sort all edges of the graph by weight.
  2. Create an empty subgraph as the MST.
  3. Go through all edges in the sorted order.
  4. Add the edge to the MST if it does not create a cycle.

The idea behind the algorithm is that you always take the cheapest edge that does not yet lead to a cycle in the MST. By proceeding this way, you will always obtain the cheapest spanning tree.

So that the algorithm does not create any cycles, the nodes are divided into connected components, based on the edges that have already been added to the spanning tree. At the beginning, all nodes are in different components. As soon as an edge is added, the two connected components become a single component. If you now add only edges that connect two components, no cycle can be created.
